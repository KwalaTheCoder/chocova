# Chocova | چوکووا

فروشگاه فارسی شکلات دست‌ساز، با HTML/CSS/JavaScript و آیکن‌های SVG.

## انتشار روی GitHub Pages

در Settings → Pages، گزینهٔ Deploy from a branch را انتخاب کنید. Branch را main و مسیر را / (root) بگذارید و Save را بزنید.

## اجرا و ویرایش

هیچ مرحلهٔ build لازم نیست. فایل‌های index.html، style.css و app.js مستقیماً قابل میزبانی هستند. تصاویر و SVG در assets قرار دارند و مسیرها نسبی‌اند تا در زیرمسیر GitHub Pages هم کار کنند.

برای پیش‌نمایش محلی: `python3 -m http.server 8000` سپس `http://localhost:8000`.

## وضعیت فروش

این نسخه انتخاب محصولات، جستجو، سبد محلی و ساخت خلاصهٔ درخواست را دارد. هنوز پرداخت، ارسال مستقیم واتساپ، پایگاه دادهٔ سفارش و ثبت کمیسیون متصل نشده‌اند. اطلاعات فرم فقط برای تهیهٔ خلاصه در مرورگر استفاده می‌شوند. قیمت و موجودی باید پیش از سفارش تأیید شوند.

تصاویر از نمونه‌های پیج Chocova تهیه شده‌اند. شمارهٔ واتساپ فروش و قیمت‌ها باید پیش از راه‌اندازی فروش واقعی تنظیم شوند.
